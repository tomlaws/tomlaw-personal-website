# Portfolio references and final direction

Research and revision: 1 November 2026.

The site introduces **Tom Law, a backend developer based in Hong Kong**. It is a personal developer site with software projects and public source repositories. The Hong Kong miniature belongs to the page background; it has no visible frame or controls.

## Sources

- [Tom's current public site](https://www.tomlaw.dev/): confirms backend development in Hong Kong, Java/Node.js, Flutter/React Native, and Go side projects. Used for factual positioning, not for its layout or hiring language.
- [Tom's GitHub profile](https://github.com/tomlaws) and its public repositories API: verified public work, original/fork status, language and repository links. The local `exp` Git remote also identifies `tomlaws`.
- [Bruno Simon](https://bruno-simon.com/) and [Choo-Choo World](https://choochooworld.com/): initial 3D world research. The final implementation uses the existing miniature as ambient identity, without requiring visitors to interact with a game or map viewer.
- [Lusion](https://lusion.co/): initial study of 3D browser composition. The final layout is a quieter developer profile rather than a studio or freelance service pitch.
- [SunCalc](https://github.com/mourner/suncalc/tree/v1.9.0): solar elevation at the harbour coordinates, supplying the live day/night amount shared with the page theme.

No third-party model, image or site copy is redistributed. The map assets and software repositories are the user's existing work. The removed Nocturne project and the superseded framed showcase are no longer part of the site.
